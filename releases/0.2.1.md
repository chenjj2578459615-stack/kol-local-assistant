# KOL 本地助手 0.2.1

- 新增 GitHub 正式版本检测，查看更新内容后可在插件内下载并应用更新。
- 合并右上角「帮助」与「检查更新」为「版本更新」，支持下次提醒、关闭自动提醒和手动检测。
- 新增 TikTok、Instagram、YouTube 平台切换及批量读取，保留关联平台主页链接和粉丝量／订阅数。
- 新增可选 AI 辅助，结合多条视频封面／缩略图、标题和标签判断达人类型；未接入仍使用本地规则。
- 优化列拖动：实时补位、上下边缘自动滚动，取消拖动恢复原顺序。
- 延用石墨白界面，保留历史批次、列设置、联系方式和平台登录状态。

首次升级到此版需运行一次安装包中的「安装或更新.cmd」，完成更新组件配置；以后在插件内更新。Instagram 需要在同一个 Chrome 用户中完成登录；AI 需自行配置支持图片的兼容服务。性别只采用本人明确声明或人工填写。
