直接在常用 Chrome 里使用

首次加载一次。以后从 Chrome 工具栏打开。

首次安装

  1. 解压插件包，双击 安装或更新.cmd。
  2. 在你已登录平台的 Chrome 中，地址栏输入 chrome://extensions，打开右上角开发者模式。
  3. 点击加载已解压的扩展程序，选择：D:\KOL本地助手\extension

工作台会自动打开。点击 Chrome 右上角的拼图图标，将 KOL 本地助手固定到工具栏。登录和授权在插件内按平台提示完成。

以后在插件内更新

  1. 点击右上角版本更新，查看更新内容并检测正式新版。
  2. 点击立即更新，自动下载、校验并切换到新版。

首次安装或从旧版升级时，运行一次本版的安装文件配置更新组件，以后无需重复运行。

数据保存在当前 Chrome 用户下。保留固定安装目录，更新时无需删除插件或重新授权。

从旧桌面版切换 / 没有看到更新提示

在当前 Chrome 打开 chrome://extensions，找到 KOL 本地助手，点击卡片上的重新加载图标。然后从工具栏打开插件。旧桌面程序不再作为入口。

请确认加载的是上面的固定目录。如果加载过其他位置的同名插件，先核对数据，避免误删原插件。不同 Chrome 用户之间不共享插件数据。
