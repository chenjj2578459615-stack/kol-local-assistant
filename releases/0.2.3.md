# KOL 本地助手 0.2.3

- 新增结果字段「互动率（Max）」：在用户设置的近 N 天／最近 N 条范围内，逐条计算「（点赞数＋评论数＋转发数）÷播放量 × 100%」，取单条最大值。
- 新字段默认放在平均播放数后，支持调整列顺序、显示隐藏和复制到 Excel；表格与复制内容统一显示两位小数百分比。
- 保留真实的 0 互动，排除零播放作品；缺少任一必要数据或范围未读全时保持为空，悬停或进入达人详情可查看原因。YouTube 不公开单条视频转发数，Instagram 也可能未提供，不以 0 代替。
- 修复 Instagram 旧资料接口不可用时整行留空，新增当前网页读取路径；视频缺少播放数时补读匹配的作品详情。
- 修复 AI 连接测试图片损坏，分别验证文字和图片输入；增加密钥格式校验，区分鉴权、权限、限流及上游错误，并显示待测试／已连接状态。
- 统计范围内没有作品时补充最近读取到的发布日期；优化繁体音乐简介的本地类型判断。

历史、草稿、联系方式、列设置、AI 配置与平台登录保留。旧批次未采集互动数时，需要重新读取才能计算互动率。性别只采用本人明确声明或人工填写。
