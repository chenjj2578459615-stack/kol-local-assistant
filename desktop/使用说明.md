# KOL 本地助手 · Windows 0.1.4

使用电脑上正式安装的 Google Chrome。首次手动加载一次插件，以后从桌面快捷方式打开。不附带或启动 Chrome for Testing。无需 Node.js 或管理员权限；支持 Windows 10 / 11 的 .NET Framework 4.8。

## 首次使用

1. 解压完整 ZIP，双击顶层的 `KOL本地助手.exe`。程序会准备固定插件目录，并显示图形操作引导。
2. 确认界面显示「Google Chrome · 已找到」。找不到时点「选择 Chrome」，选择平时使用的 Chrome 安装目录中的 `chrome.exe`。本机尚未安装 Chrome 时请先安装正式版。
3. 点击「打开扩展管理页」。如有多个 Chrome 用户，先切换到平时登录 TikTok 的用户。在页面右上角打开「开发者模式」。
4. 在程序中点击「复制插件路径」。回到 Chrome，点击「加载已解压的扩展程序」。在文件夹选择器的地址栏粘贴路径、按回车，再点击「选择文件夹」。
5. 路径应直接包含 `manifest.json`。不要选择 ZIP、EXE，也不要选择整个桌面安装包。使用程序复制的路径即可。
6. 程序自动检测插件，显示「插件已连接，可以开始使用」并打开工作台。已经加载但仍等待时，请确认插件已开启并点击重新加载，再返回程序；仍未连接可点「修复连接」。检测超过 25 秒会显示具体排查步骤。
7. 工作台里分别显示 TikTok、Instagram 的状态。点击对应的「授权连接」，同意网站读取权限；已有登录会在安装插件的同一个 Chrome 用户中使用。需要登录或验证码时，只在平台官方页面完成。Instagram 仅在需要读取其粉丝量时连接。

关闭桌面程序不会关闭 Chrome 或清除任务；浏览器中插件的本机连接会保持。以后双击桌面快捷方式，程序检测到插件后切到已有工作台。浏览器关闭、插件停用时会提示打开 Chrome 或重新启用；不会把尚未连接显示成已成功。

## 日常使用

每位达人一行填写 TikTok 主页和联系方式，Instagram 账号与粉丝量选填。Excel 的多行数据可直接粘贴到输入格，或使用「从表格导入」确认列对应。品牌关键词固定检索最近 180 天，视频数不限，不使用 AI。输出保留原定 12 个字段，列顺序可调整。

插件只重连或必要时刷新自己创建的采集页，切回工作台不会主动刷新已有登录页。保持 Chrome 和采集页开启；电脑休眠、Chrome 退出、平台限制期间无法继续。Chrome 节能/内存节省可能影响后台页面，插件会保留进度并尝试恢复；登录和安全验证仍需本人处理。

## 更新

1. 打开「更新与设置」，导入维护者提供的新版桌面 ZIP。配置可用的 HTTPS 更新源后也可在线检查、下载和校验。
2. 先在工作台暂停采集，再点击「应用更新」。正在运行的采集会阻止更新，避免丢失进度。
3. 按主界面提示打开 Chrome 扩展管理页，在「KOL 本地助手」卡片上点击重新加载按钮，再刷新已有工作台页面。
4. 程序识别到插件的新版本后显示已连接。文件已更新但 Chrome 仍运行旧代码时，会显示「等待重新加载插件」，不会误报完成。

插件目录固定，不需要卸载、重新加载其他文件夹或关闭整个 Chrome。请勿卸载本插件，否则 Chrome 本地任务可能被删除。下载/校验失败时保留当前版本。当前没有预置线上发布地址，不能视为已启用在线自动更新。启动器尚未签名，新电脑可能显示 Windows 来源提示。

## 文件位置与旧版数据

从 D 盘启动的新安装默认使用 `D:\KOL本地助手`，其他非系统盘同理；从系统盘启动则使用 `%LOCALAPPDATA%\KOLLocalAssistantChrome`。已创建的快捷方式和后续安装沿用记录的目录，支持 `--data-root=绝对路径`。程序中的「打开文件夹」可以查看实际加载路径。

任务和登录保存在安装插件的 Chrome 用户中。程序目录只保存安装文件、更新包、设置和插件版本/运行状态；不会复制密码、Cookie 或验证码。本机连接只允许固定身份的 KOL 插件访问，无需开放网络端口。

旧版 0.1.2 / 0.1.3 的专用浏览器任务和登录仍保留在原目录，不自动迁入正式 Chrome；先从旧工作台复制结果留存，再导入达人链接和联系方式。不要删除旧 `browser-profile` 来完成迁移。普通 Chrome 中若已有另一份独立安装，也先复制其结果留存，两份插件的任务不会自动合并。

## 当前验证边界

自动化测试使用独立测试资料目录，不操作日常 Chrome 用户资料。真实 TikTok 登录后的 180 天全量视频、真实 Instagram 粉丝量和另一台实体电脑安装仍需验收。平台无法读取时明确暂停并保存进度，不会把不完整数据当作完成。
